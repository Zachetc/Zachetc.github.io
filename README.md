A complete static website prepared for https://zachetc.github.io.

## Publish for free using GitHub Pages

1. Sign in to GitHub as Zachetc and open https://github.com/new.
2. Create a PUBLIC repository named exactly `Zachetc.github.io`.
3. Extract this ZIP on your computer. On the empty repository page, choose "uploading an existing file". Upload the extracted files and the `assets`, `work`, and `notes` folders into the repository root. Do not upload the ZIP itself or an extra enclosing folder. Commit the upload to `main`.
4. Open repository Settings > Pages. Under Build and deployment, select "Deploy from a branch", choose `main` and `/(root)`, then Save.
5. Wait for the deployment to finish. GitHub will display the live site address: https://zachetc.github.io.

The package includes all pages, images, fonts and font licenses, JavaScript, CSS, résumé, and SEO metadata. No build tools or paid hosting plan are required. The `.nojekyll` file bypasses Jekyll processing; include it if it appears in your extracted files.

Professional experience and individual achievements use the supplied résumé and linked public records. The Sources & Recognition page explains attribution. Career aspirations are goals. Contact information and résumé are intentionally public as part of the portfolio.
