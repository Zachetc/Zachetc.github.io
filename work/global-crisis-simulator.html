The question behind the model

Interconnected systems can turn a local disruption into a wider shortage. This project explores how the structure of dependencies changes the path of a shock and the time it takes a system to recover.

An interpretable simulation

The framework connects a network builder, shock injection, propagation logic, recovery curves, fragility ranking, and visualization. NetworkX supports quick iteration on directed dependency networks.

  • Explored chokepoint disruptions, infrastructure shocks, and correlated slowdowns.
  • Modeled capacity degradation and deterministic recovery curves.
  • Compared unmet demand, recovery timing, shortage accumulation, and node fragility.
  • Kept scenario definitions and experiment runners available in the repository.

What the project produced

A scenario library and visual outputs make it possible to compare how different disruptions behave under the model’s assumptions. The value is in inspecting mechanisms and asking better questions about structural vulnerability.

How to interpret it

This is a scenario-exploration tool. It does not forecast geopolitical events or real-world economic outcomes.

The network is stylized, propagation is deterministic, recovery curves are simplified, and fragility scores are heuristic. Real trade-weight calibration and probabilistic extensions are potential future directions.
